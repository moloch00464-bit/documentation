# M.O.L.O.C.H. 3.1 - Widget Setup

## 📱 Widgets installieren:

```bash
# 1. Widgets kopieren
mkdir -p ~/.shortcuts
cp ~/documentation/widgets/*.sh ~/.shortcuts/
chmod +x ~/.shortcuts/*.sh

# 2. Fertig!
```

## 🎯 Verfügbare Widgets:

- **moloch_voice** - Startet M.O.L.O.C.H. Voice Mode
- **moloch_vision** - Startet M.O.L.O.C.H. Vision Mode (Foto)

## 📱 Widget auf Home-Screen:

1. Termux Widget App installieren (falls nicht vorhanden):
   - Play Store: "Termux:Widget"

2. Lange auf Home-Screen drücken
3. Widget hinzufügen
4. "Termux:Widget" auswählen
5. Widget erscheint mit allen Scripts aus `~/.shortcuts/`

## ✅ Fertig!

Jetzt kannst du M.O.L.O.C.H. direkt vom Home-Screen starten!
